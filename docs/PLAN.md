## Phase 12〜19：新しい UI（v5）で「続く日記」にする（2026-10-24 決定。全44タスク）

背景は「日記が続く仕組み」の調査（Day One / Daylio / Finch / muute ＋ 継続の研究）。提案 A〜H のうち **E（書く時刻の初回設定・節目の問い・通知）は今回やらない**。UI は**プロトタイプ v5 で進める**ことに決定。

**画面の見た目・動きの正：`docs/prototype/ui-v5.html`**（ブラウザで開くと、スマホ枠の中で触れる。気分を選ぶ回転盤 → 一言 → ホーム → 手紙、下の3タブ、風の記録まで入っている）。実装は、各画面をこのプロトタイプに合わせる。書体はネットから読み込む。

**機能は増やさない。次の2つのどちらにも効かないものは入れない：①書くハードルを下げる／続ける ②過去の自分の言葉が今の自分を助ける。**
**軸にする原則：「過去の自分に今助けてもらう」（AI 憲法の前文・第4条）。画面に出る本人の文章は AI が書き換えない。相談では本人の言葉をそのまま引く。**

**確定した UI 仕様（v5）**
- **起動画面**：アプリを開くと、革の机の上に紙のカードが落ち、緑のインクで「mind」が1文字ずつ現れ、鏡像の「wind」が落ちてくる（`docs/brand/mindwind-opening.svg` のロゴと動き）。最後に**「タップしてスタート」**が明滅し、**どこをタップしても気分の回転盤へ**（途中のタップは演出を飛ばす）
- **ログインは最初に求めない**：初回は起動画面から気分選びへ。裏でゲスト（匿名）として自動的に始める。Google 連携は**設定**でできる（連携しても記録はそのまま引き継がれる）。**確定（2026-10-24）**：①ゲストの1日の上限は今のまま（会員の1/10）②**連携を促す小さな案内を出す**（ゲストのときだけ・ホームの下・閉じられる）③**呼び名は設定で変える。設定を開かなければ自動の呼び名**（風にちなんだ名前を人ごとに割り当てる：春風・薫風・涼風・朝風・夕風・海風・山風・若葉風・初風＋「さん」。**気分の玉の名前〔追い風・そよ風・凪・向かい風・嵐〕とは重ねない**。ユーザー番号から決めるので、同じ人はいつも同じ名前。AI には渡さない）④**ボット対策は今入れる**（App Check と IP レート制限。入口を自動ゲストにする分、悪用されたときの費用を守る）
- **世界観**：革のデスクマットの緑（粒・ムラ・ランプの明かり・縫い目）の上に、紙（繊維・ふちのゆらぎ・影）が置かれる。線は鉛筆、手紙は緑インクのペン字。光沢・ガラス・汎用の線画アイコンは使わない
- **書体**：見出し＝Kiwi Maru／あなたの言葉＝Yomogi／補助＝Klee One／メンターの手紙＝Zen Kurenaido（緑インク）／UI＝Zen Maru Gothic。明朝は使わない
- **気分の玉**：追い風・そよ風・凪・向かい風・嵐の5つ。水彩の紙の玉に、鉛筆で風を描く。**今日の気分は1か所の値から、帯・手紙・風の記録・封蝋・一言の画面のすべてに同じ玉で出す**
- **ボタン**：丸いアイコンボタン（紙の札／緑／チョーク風の点線）。文字は小さく添えるだけ。独自の鉛筆アイコン（鉛筆・開いたノート・眠る月・紙飛行機・しおり・判子・束ねた紙・風の渦・マイクなど）
- **操作の位置**：親指の弧（画面下3分の1）に操作を集め、上は見るだけ
- **3タブ**：ホーム（束ねた紙）／記録（開いたノート）／相談（風の渦）
- **入力**：回転盤で気分を選ぶ／一言・記録は**長押しで封をして保存**／相談の入力欄は行が増えると**上へ大きくなり（5行まで）**、空のときはマイク・文字があるときは紙飛行機の1ボタン／上限の約9割から赤字のカウンター、上限で入力欄が揺れる
- **手紙**：テープをはがす → フタが開く → **親指で手紙を引っぱり出す**（離すと戻る・タップでも出る）→ 封筒は下へ落ち、**三つ折りの便箋が折り目で1枚ずつ開く**。引用はマスキングテープで貼った切れ端
- **風の記録**：ホームの「今週の便箋」の帯をタップ → 月（日ごとの玉）／年（1日＝1つぶの点）。前後移動、年から月へ
- **フィードバック**：振動（Android のみ）・音（初期オフ）・「動きを減らす」設定

**確定した仕様（2026-10-24 ユーザー回答）**
- **記録フローの変更（成形を裏へ）**：「日記 → 深掘り（1問・スキップ可）→ 保存」の2段階にする。**6項目への成形カードは画面から無くす**。画面に出るのは本人の文章＋深掘りの質問と答えだけ。AI の整形は裏だけで行う
- **裏で RAG に渡す中身**：本人の言葉を**書き換えずにチャンク分割**して保存・ベクトル化する。AI は検索用の一行メタ（出来事・感情など）を足すだけで、メタは検索の精度を上げるために使い、**画面にも相談の回答にも出さない**。相談で AI に渡すのは本人の言葉のチャンク（＋日付）
- **A（気分スタンプ＋10秒記録）**：**その日の最初にアプリを開いたとき1回だけ**、ホームの前に「今日の気分は？」の玉の回転盤を出す。スキップ・選び直しもできる。選んだあとに「**一言だけ書く／しっかり書く／今日はここまで**」の3択を聞く。玉だけで終えた日も**1日分として数え**（風の記録・今週の便箋の帯・ストリーク）、RAG には入れない。気分は日付ごとの別データ（`moods/{date}`）。「一言だけ」は `thoughts` に `kind: "quick"` で保存し、通常の記録と同じ扱い。あとから深掘りを足せる。チップ（今日あったこと）は作らない
- **C**：週の手紙は**開いたときに生成**（スケジューラ・通知なし）。生成物は `users/{uid}/letters/{週キー}` に保存し、RAG には入れない
- **H**：下書きの自動保存（端末内だけ。音声入力は実装済み）
