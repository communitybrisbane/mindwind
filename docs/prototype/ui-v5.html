3タブ v5（ホーム・記録・相談）

下の3タブ（ホーム／記録／相談）を行き来して触れます。最初の気分スタンプ → ホーム、の流れも前のままです。

回転盤の遊び方

  • 盤の上を左右になぞって回す。弾くと勢いで回り続け、だんだん止まる。
  • 回るたびにカラカラ（音をオンに）。上の紙の矢印がはじかれる。
  • 真ん中の文字がリールのように回って、いまの玉の名前と説明が出る。
  • 止まった真ん中の玉をタップすると、今日の気分に決まる。横の玉をタップすると、その玉が真ん中まで回ってくる。

風の強さで変わる雰囲気

  • 回転盤で止まった（セットした）とき：真ん中の玉の風の雰囲気が、背景にうっすら出る。回している間は、いったん静まる。
  • 玉をタップして決めたとき：その雰囲気がグワッと全力で出る。追い風＝光が弾け、花びらが玉から放射状に広がる。そよ風＝黄緑の光と葉が広がる。凪＝無風。ふっと暗くなって、動きがすべて止まる（音もなし）。向かい風＝突風が正面から吹きつけ、画面が暗くなって揺れる。嵐＝暴風。雨と風が一気に襲い、画面が震え、稲光は1回だけのやわらかい明るさ。
  • 嵐は約3秒で弱まります（荒れたまま止めない）。点滅はしない。「動きを減らす」では色の変化だけ。音は「音」オンのときだけ（嵐・向かい風＝風の音、追い風＝やさしい鈴）。振動は Android のみ。上のボタンで、どの画面でも「グワッ」を試せる。
  • 決めたあとの1日は、ホームなどの背景に、その風の色がうっすら残る。

ログインのしくみ（設定）

  • 最初はログイン不要：起動画面 → 気分、の流れ。裏でゲスト（匿名）として自動的に始まる。
  • ホームの右上の歯車から設定へ。アカウント欄は、ゲストなら「ゲスト／30日使わないと消える」と、緑の「守る」ボタン。押すと Google のアカウント選択（本番では Google の標準画面）。
  • 連携できたら：「Googleでつながっています」に変わり、記録はそのまま引き継がれ、上限が広がる。
  • すでに使われているアカウント（さくら）を選ぶと、ログインし直しの確認（いまのゲストの記録は消えると警告）。
  • 連携を促す案内：文字のフッターは出さず、歯車に小さな赤い点だけ（ゲストのとき）。設定を開くと消え、連携しても消える。
  • 呼び名：設定を開かなければ、自動の呼び名（風見さん〜）。入れるとホームの挨拶と手紙の宛名がすぐ変わる。
  • ログアウト：ゲストは「記録に戻れなくなる」と警告（つなぐ／ログアウト／やめる）。削除は赤いボタンを長押し。

起動画面（ロゴ）

  • アプリを開くと、革の机の上に紙のカードが落ちてきて、緑のインクで「mind」が1文字ずつにじんで現れ、そのあと鏡像の「wind」が上から落ちてきます（ロゴの動きそのまま）。風が1本ずつ横切ります。
  • 動きが終わると、下に「タップしてスタート」がゆっくり明滅し、その上で波紋が広がります。どこをタップしてもカードが上へ去り、気分の回転盤が始まります。動きの途中でタップすると、動きを飛ばします。
  • ロゴは docs/brand/mindwind-opening.svg をそのまま使用。カードの下の一行は、アプリのコンセプトの文です。

v5 で足したところ

  • 3タブ：ホーム（束ねた紙）／記録（開いたノート）／相談（風の渦）。アプリの実際の並びに合わせた。
  • 記録タブ：罫線ノートに書く → 「書き終えた」で、メンターが緑インクで深掘りの1問を余白に書く → 答えを書く（とばしてもよい）→ 長押しで封をして保存。成形カードは出ない（自分の文章のまま）。
  • 相談タブ：文通。あなたの問いは付箋、メンターの返事は便箋（緑インク）。返事の下に「読み返したページ」＝あなたの過去の記録（タップで全文）。下の入力欄に書いて紙飛行機で送ると、返事が書かれていく。
  • 風の記録：ホームの「今週の便箋」の帯をタップすると、月のカレンダー（日ごとの玉）が開く。下の「年」で、12か月の小さな玉の一覧（1日＝1つぶ）に切り替わり、月をタップするとその月へ。前後の矢印で月・年を移動。
  • 手紙の開き方を作り直し：テープをはがす → フタが開く → 親指で手紙を上へ引っぱり出す（離すと戻る／タップでも出る）→ 封筒は下へ落ち、三つ折りの便箋が折り目で1枚ずつ開く。
  • （旧）手紙の開き方を修正：フタの裏が手紙の手前に来る誤りを直し、封筒から出た手紙がそのまま大きな便箋になるようにつないだ。

v4 で変えたところ

  • 書体：明朝をやめ、やわらかい丸み（Kiwi Maru）＋手書き（Yomogi／Klee One）に。メンターの手紙はペン字（Zen Kurenaido・緑インク）。
  • アイコン：汎用の線画をやめ、鉛筆で描いた独自のもの。一言＝鉛筆と一筆の線／しっかり＝風の渦がある開いたノート／ここまで＝眠る月／相談＝紙飛行機／あとで＝しおり／保存＝判子／ホーム＝ひもで束ねた紙。線は二重のラフスケッチ。
  • 手紙：カードめくりをやめ、罫線の便箋が三つ折りで開く。引用はマスキングテープで貼った切れ端。マーカーの下線、手書きの署名。下へスクロールして読む。
  • 背景：革のデスクマット。粒（しぼ）・ムラ・ランプの明かり・かすかなカップの輪じみ・縫い目。
